# Project guidance

- Build an original boss-combat game; do not copy protected game assets or code.
- Follow ROADMAP.md one gate at a time. Keep the first playable goal to one arena, one player, and one boss.
- Before substantial implementation, state the current milestone and its pass criteria. After implementation, record a playable check and available performance measurements.
- Treat Unreal Engine as a candidate, not a final decision, until milestone 0 is evaluated on this Mac.
- Prefer small, reversible changes and placeholder assets. Do not install large toolchains or generate a full engine project merely to update documentation.
- Keep README.md and ROADMAP.md current when a decision or milestone changes.
